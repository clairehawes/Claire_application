# Event Planner

A simple web app for planning and tracking events. No installation or build step: open `index.html` in a web browser.

## What it holds for each event

- **Event details**: event name, location, start and end dates, expected number of attendees, budget and notes
- **Attendees**: attendee list with email, phone, company, RSVP status and dietary or access needs, plus attendee and confirmed counts. You can download the list as a CSV file.
- **Agenda**: sessions grouped by day (Day 1, Day 2, …) with times, room and notes
- **Suppliers**: suppliers used, the service each provides, contact details, and total spend with each one
- **Budget and invoices**: each cost with supplier, invoice number, due date and paid or unpaid status. It shows total spend, the amount paid, the amount outstanding and the budget remaining. Click a status badge to switch it between paid and unpaid.
- **Contacts**: the event planner's and all suppliers' contact details on one page, with links to phone or email them

## Data

Your data is saved in your web browser on this device. Use **Export** to save a backup file (JSON). Use **Import** to load a backup on another device or browser. **Print** gives you a printable copy of the tab you're viewing.

The app starts with a sample event so you can see how it works. Delete it when you no longer need it.
